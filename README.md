Hello this is a investment program made for calculating simple, compound, or continuously compounding interest from user provided input of principal, rate and any time period they choose.  
The growth chart simulates earnings over a course of five years only to visualize how the investment grows over time using example yearly return rates.

  
Libraries used: 
- math  
- numpy  
- pandas  
- matplotlib  
  
How to run:  
``` 
pip install -r requirements.txt  
python invest_program_final.py    
```
